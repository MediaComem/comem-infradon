# Révisions pour l'examen final - InfraDon

Ce dossier contient un [examen type](examen-type.md) pour vous préparer à l'examen final.

> **Durée :** 2h, sur papier\
> **Documents autorisés :** une feuille A4 recto-verso manuscrite

## Ce qu'il faut maîtriser pour l'examen

- [Cours 2 - Import et nettoyage](../cours/02-import-nettoyage.md) : qualité des données, stratégie staging, fonctions de nettoyage, idempotence et ON CONFLICT
- [Cours 3 - Transactions et concurrence](../cours/03-transactions-concurrence.md) : propriétés ACID, niveaux d'isolation, anomalies de concurrence, FOR UPDATE, deadlock
- [Cours 4 - Sécurité, rôles et sauvegarde](../cours/04-securite-roles-sauvegarde.md) : GRANT/REVOKE, rôles, suppression physique ou logique, pg_dump/pg_restore
- [Cours 5 - Structures et architectures](../cours/05-structures-architectures.md) : lire un EXPLAIN ANALYZE, types d'index et quand les utiliser, types NoSQL, ETL/ELT, Medallion, OLTP/OLAP, read replica, data warehouse/lake, CAP, data mesh
- [Cours 6 - Éthique des données](../cours/06-ethique-donnees.md) : données personnelles, privacy by design, biais algorithmique, souveraineté numérique
