# Révisions pour l'examen final - InfraDon

Ce dossier contient un [examen type](examen-type.md) pour vous préparer à l'examen final.

> **Durée :** 2h, sur papier\
> **Documents autorisés :** une feuille A4 recto-verso manuscrite

## Ce qu'il faut maîtriser pour l'examen

- [Cours 2 - Fondamentaux](../cours/02-fondamentaux.md) : propriétés ACID
- [Cours 3 - Import et nettoyage](../cours/03-import-nettoyage.md) : stratégie staging, fonctions de nettoyage, comportement des JOIN
- [Cours 4 - Transactions et concurrence](../cours/04-transactions-concurrence.md) : niveaux d'isolation, anomalies de concurrence, FOR UPDATE, deadlock
- [Cours 5 - Optimisation et indexation](../cours/05-optimisation-indexation.md) : lire un EXPLAIN ANALYZE, types d'index et quand les utiliser
- [Cours 6 - Sécurité, rôles et sauvegarde](../cours/06-securite-roles-sauvegarde.md) : GRANT/REVOKE, rôles, pg_dump/pg_restore
- [Cours 7 - Structures et architectures](../cours/07-structures-architectures.md) : types NoSQL, ETL/ELT, Medallion, OLTP/OLAP, read replica, data warehouse/lake, CAP, data mesh
- [Cours 8 - Éthique et données](../cours/08-ethique-donnees.md) : données personnelles, privacy by design, biais algorithmique, souveraineté numérique
